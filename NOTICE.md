# Project provenance

Internal Command Protocol concept and supplied v2 whitepaper: CrypTony.
Original prototype implementation developed with Michael Gee and AI coding
assistance. This is a standalone project, separate from Geek Protocol, hosted
under GEEKProtocol0110 while it is developed.

The original implementation and project-authored documentation are provided
under the MIT license in LICENSE. The source papers are not included or
relicensed here. Kaspa, SilverScript and other dependencies retain their
upstream licenses and notices.

Public, open-source development follows the author's stated publication
preference conveyed by Michael on October 18, 2026. This is not an assertion
that the author has reviewed or audited the implementation. Its security
target is narrower than claims made in the paper. It is not quantum-safe,
independently audited or ready for mainnet funds.

Private test session keys and operator state are excluded from this repository.
