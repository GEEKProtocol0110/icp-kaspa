# Project notices

Internal Command Protocol is a standalone Kaspa testnet research prototype
based on the supplied ICP v2 technical whitepaper.

The original implementation and project-authored documentation are provided
under the MIT license in LICENSE, attributed to ICP contributors. The source
papers are not included or relicensed here. Kaspa, SilverScript and other
dependencies retain their upstream licenses and required notices.

The implementation has not been reviewed or audited by the paper's author.
Its security target is narrower than claims made in the paper. It is not
quantum-safe, independently audited or ready for mainnet funds.

Private test session keys and operator state are excluded from this repository.
