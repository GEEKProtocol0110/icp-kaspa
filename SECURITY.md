# Security

Internal Command Protocol (ICP) is an experimental Kaspa Testnet-10 research prototype. It is not a launched product. No independent security audit has been completed. Dated testnet runs and local labs are records of those experiments. They are not a production guarantee. The current compromise model is [docs/SECURITY-TARGET.md](docs/SECURITY-TARGET.md).

## Reporting a vulnerability

Private vulnerability reporting is enabled for this repository. Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/GEEKProtocol0110/icp-kaspa/security/advisories/new). Do not open a public GitHub issue for an unpatched vulnerability.

Geek Protocol's organization security policy is [SECURITY.md in geek-protocol-hq](https://github.com/GEEKProtocol0110/geek-protocol-hq/blob/main/SECURITY.md). That document describes Geek Protocol HQ. It is not an audit of this repository.

Include the affected commit, what you expected, what you observed, and the smallest evidence that explains the issue. Do not include seed phrases, private keys, wallet files, or session backups. This project does not ask for them.

Public fixture keys in this repository are intentionally known. Never fund fixture addresses.
